# Changelog

## 1.0.1 - 2026-08-21

- Force clipboard, reminder, menu, and confirmation strings to render as plain
  text, preventing QML rich-text resource loading from untrusted content.
- Add a plugin-local plain-text confirmation dialog for dynamic labels.

## 1.0.0 - 2026-08-20

- Initial public release.
- Unified apps, Omarchy actions, and live Hyprland keybindings.
- Added scoped clipboard history, emoji, and reminder views.
- Added native global shortcut and bar-widget entry points.
- Preserved Omarchy's fullscreen image picker as a standalone overlay.
